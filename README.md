# 🚀 Agent-Quickstart: 一文讲透大模型智能演进之路

欢迎来到 **Agent-Quickstart**。这是一个旨在帮助开发者从零开始，系统性地掌握大模型（LLM）从简单的“对话框”进化到“自主智能体（Agent）”再到“行业技能模块（Skill）”的实战指南。

通过本项目，你将通过**文档（Docs）+ 示例代码（Code）**的双向互动，透彻理解大模型能力的每一次跃迁。

---

## 🌟 大模型智能进化图谱

我们将大模型的能力演进划分为六个“段位”，每个段位都代表了解决特定问题的关键技术。

### 1. 铸铁：基础交互（LLM as a Chatbot）
*   **核心痛点**：如何让模型听懂指令？
*   **技术内涵**：最基础的“一问一答”。通过 Prompt Engineering（提示工程）优化输入，让模型输出更符合预期的文本。
*   **相关资源**：
    *   📖 [01-铸铁-大模型核心交互雏形.md](docs/01-铸铁-大模型核心交互雏形.md)
    *   💻 [01_基础交互_一问一答示例.py](code/01_基础交互_一问一答示例.py)

### 2. 青铜：知识增强与工具基础（RAG & Tools）
*   **核心痛点**：模型有“幻觉”，且不知道实时信息。
*   **技术内涵**：
    *   **RAG（检索增强生成）**：给模型一本“参考书”，让它基于私有知识库回答。
    *   **Tools**：初步引入外部工具（如搜索、计算器），拓宽模型的边界。
*   **相关资源**：
    *   📖 [02-青铜-大模型知识增强与基础工具能力.md](docs/02-青铜-大模型知识增强与基础工具能力.md)
    *   💻 [02_工具调用_Tools基础示例.py](code/02_工具调用_Tools基础示例.py) | [03_知识增强_RAG示例.py](code/03_知识增强_RAG示例.py) | [04_知识增强_联网搜索示例.py](code/04_知识增强_联网搜索示例.py)

### 3. 白银：任务执行能力（Function Call）
*   **核心痛点**：模型只会“说”，不会“做”。
*   **技术内涵**：**Function Call**。模型不再只是生成文本，而是能根据需求输出结构化的 JSON 参数，从而驱动外部函数执行具体任务（如订票、查数据库）。
*   **相关资源**：
    *   📖 [03-白银-大模型任务执行能力.md](docs/03-白银-大模型任务执行能力.md)
    *   💻 [05_任务执行_FunctionCalling示例.py](code/05_任务执行_FunctionCalling示例.py)

### 4. 黄金：智能代理（Agentic AI）
*   **核心痛点**：复杂任务需要多步决策，模型容易跑偏。
*   **技术内涵**：**Agent**。引入 **ReAct（Reason + Act）** 循环，让模型学会“思考 -> 行动 -> 观察 -> 再思考”。它具备了初步的自主规划和自我纠错能力。
*   **相关资源**：
    *   📖 [04-黄金-Agent智能代理.md](docs/04-黄金-Agent智能代理.md)
    *   💻 [06_ReactAgent_示例.py](code/06_ReactAgent_示例.py)

### 5. 铂金：任务协同能力（MCP）
*   **核心痛点**：多个 Agent 之间、Agent 与复杂系统之间如何高效协同？
*   **技术内涵**：**MCP（Model Context Protocol）**。一种标准化的协议，将外部能力（工具、资源、上下文）以统一的方式暴露给模型。它解决了能力复用和多系统解耦的问题。
*   **相关资源**：
    *   📖 [05-铂金-大模型任务协同能力.md](docs/05-铂金-大模型任务协同能力.md)
    *   💻 [07_任务协同_MCP-Server示例.py](code/07_任务协同_MCP示例/07_任务协同_MCP-Server示例.py) | [07_任务协同_MCP-Client示例.py](code/07_任务协同_MCP示例/07_任务协同_MCP-Client示例.py)

### 6. 钻石：智能执行能力（Skill）
*   **核心痛点**：Agent 执行长链路任务依然不稳定，且能力难以在不同场景间快速迁移。
*   **技术内涵**：**Skill（技能）**。将指令、工具、知识和执行逻辑封装为标准化的、可复用的"技能模块"。它是大模型能力的"容器化"，真正打通了生产力落地的最后一公里。
*   **相关资源**：
    *   📖 [06-钻石-大模型智能执行能力.md](docs/06-钻石-大模型智能执行能力.md)
    *   💻 [08_智能执行_Skill示例.py](code/08_智能执行_Skill示例/08_智能执行_Skill示例.py)

## 🛠️ 快速开始

### 1. 环境准备
确保你已安装 Python 3.10+，并安装必要依赖：
```bash
pip install -r requirements.txt
```

### 2. 配置 API
在 `code/config.py` 中填入你的硅基流动（SiliconFlow）或其他兼容 OpenAI 协议的 API Key。

### 3. 运行示例
你可以从基础交互开始尝试：
```bash
python code/01_基础交互_一问一答示例.py
```

或者直接体验高级的 ReAct Agent：
```bash
python code/06_ReactAgent_示例.py
```
